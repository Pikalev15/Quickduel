# QuickDuel contributor instructions

Follow [the brand and copy guide](docs/brand-and-copy.md). Keep QuickDuel's established typography and palette. Use direct player-facing language, concrete gameplay examples and clear actions. Do not add em dashes or generic promotional filler. Use simple rows rather than unnecessary cards or pill tags. Preserve touch-target sizes, reduced-motion support and authoritative timing.

Run `npm run check:copy`, lint, typecheck, unit tests and Playwright before release. Review mobile and desktop previews. Keep production deployment and database changes separately authorized.
